# Galeria SAPO — André Aires, 2002–2008

Fotografias recuperadas dos sítios pessoais antigos de André Aires no SAPO (`*.no.sapo.pt`) e no Planeta Clix (`andreaires.planetaclix.pt`).

Esta galeria existe só para partilha direta. Os motores de busca estão bloqueados (`robots.txt` e `<meta name="robots" content="noindex">`), porque inclui fotografias de amigos.

Recuperado a 25 de novembro de 2026 a partir do Arquivo.pt e do Wayback Machine.
